# TicketRush — 티켓팅 실전 연습 시뮬레이터

실전은 단 한 번입니다. 연습은 몇 번이든.

국내 예매처의 실제 예매 흐름(대기열 · 보안문자 · 좌석 선점 경쟁 · 서버 지연)을 재현하고,
끝나면 반응속도와 클릭 습관을 분석해 무엇을 고쳐야 하는지 알려주는 연습 도구입니다.

**빌드 도구나 서버가 필요 없습니다.** `index.html`을 브라우저로 열면 바로 실행됩니다.

## 실행 방법

`index.html` 더블클릭, 또는

```bash
start "" index.html
```

## 연습 흐름

```
오픈 대기 → 대기열(대기번호) → 보안문자 → 날짜/회차 → 구역 → 좌석(포도알) → 결제 → 분석
```

1. **오픈 대기** — 버튼이 활성화되는 순간의 반응속도를 측정합니다. 미리 누르면 무효 처리됩니다.
2. **대기열** — 반응속도가 대기번호를 결정합니다. 새로고침하면 순번이 뒤로 밀립니다.
3. **보안문자** — 실제 예매처처럼 좌석을 보기 전에 나옵니다. 여기서 흘린 시간만큼 좌석이 팔립니다.
4. **날짜/회차** — 회차마다 경쟁률이 다릅니다. 주말·막공은 좌석이 더 빨리 사라집니다.
5. **구역** — 공연장 좌석배치도에서 구역을 고릅니다. 색이 옅을수록 많이 팔린 구역입니다.
6. **좌석** — 포도알을 선택합니다. 좋은 자리일수록 남에게 뺏길 확률이 높습니다.
7. **분석** — 7개 지표를 벤치마크와 비교하고, 개선 방법을 문장으로 제시합니다.

## 측정 지표

| 지표 | 설명 |
|---|---|
| 반응속도 | 오픈 순간부터 예매 버튼 클릭까지. 결과의 절반 이상을 결정합니다. |
| 회차 선택 소요시간 | 미리 정해두지 않으면 이 구간에서 좌석이 사라집니다. |
| 좌석 선택 소요시간 | 좌석 화면 진입부터 첫 좌석 확보까지. |
| 클릭 정확도 | 전체 클릭 중 유효한 대상을 누른 비율. |
| 마우스 경로 효율 | 최단거리 대비 실제 커서 이동거리. |
| 연속 클릭 속도 | 가장 빠른 1초 구간의 클릭 수. |
| 침착도 | 불필요한 새로고침·연타·매진 좌석 클릭이 적을수록 높습니다. |

## 공연장

홈 화면에서 6개 공연장 중 하나를 고릅니다. 공연장마다 좌석배치도 구조가 다릅니다.

| 공연장 | 구조 |
|---|---|
| 예술의전당 콘서트홀 | 정면 부채꼴 객석 + 뒤쪽 발코니 + 측면 박스석 |
| 잠실실내체육관 | 사각 플로어를 1·2층이 둥글게 감쌈 |
| 인스파이어 아레나 | 플로어 + 100·200·300번대 말발굽형 |
| KSPO DOME (체조경기장) | 플로어 + 3개 층이 원형으로 둘러쌈 |
| 고척스카이돔 | 그라운드 + 내야·외야·상단석 부채꼴 |
| 서울월드컵경기장 | 사각 그라운드를 스탠드가 마주보는 구조 |

배치도는 `사각 블록` · `도넛 조각` · `다각형` 세 가지 도형을 조합해 그립니다
(`js/data.js`의 각 구역 `shape` 필드).

> 실제 공연장의 구조(플로어 배치, 층 수, 감싸는 각도, 스탠드 형태)를 참고해 비율을 맞춘
> **재구성**입니다. 공식 좌석배치도를 그대로 옮긴 것이 아니므로 구역 번호와 좌석 수는 실제와 다릅니다.

## 랭킹

랭킹에는 **이 브라우저에 실제로 저장된 기록만** 올라갑니다. 가상의 경쟁자를 만들지 않습니다.
홈 화면에서 플레이어 이름을 바꿔가며 여러 사람이 같은 기기로 겨룰 수 있습니다.
인터넷 전체 랭킹을 만들려면 서버가 필요합니다 (`TP.store`를 서버 호출로 바꾸면 됩니다).

## 구조

```
index.html          화면 골격
css/style.css       전체 스타일
js/core.js          네임스페이스 · 시드 난수 · 유틸 · 이벤트버스
js/data.js          공연 · 공연장 배치도 기하 · 난이도 · 벤치마크
js/telemetry.js     클릭 · 마우스 · 구간 시간 계측
js/sim.js           서버 부하 · 응답 지연 · 대기열 엔진
js/seats.js         좌석 배치 생성 · 경쟁자 좌석 소진 엔진
js/rank.js          실제 기록 기반 랭킹
js/analysis.js      지표 환산 · 피드백 생성
js/ui.js            렌더링 · 좌석배치도 SVG · 캔버스 차트
js/app.js           진행 상태기계
```

의존성 없는 순수 HTML/CSS/JavaScript입니다.

## 안내

개인 연습용 시뮬레이터입니다. 실제 예매 사이트와 무관하며 어떤 예매처와도 통신하지 않습니다.
자동화·매크로 기능은 제공하지 않습니다.
