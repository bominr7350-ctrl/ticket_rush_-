TicketRush 관리자

방문 통계를 보려면 Supabase 에 넣어둔 관리자 토큰이 필요합니다. 토큰은 이 브라우저에만 저장되며 서버로 저장되지 않습니다.

아직 준비가 안 됐나요? — 처음 한 번만 하는 설정
  1. Supabase 대시보드 → SQL Editor 를 엽니다.
  2. 아래 SQL 을 붙여넣고 실행합니다. 위 칸에 토큰을 먼저 입력하면 그 토큰이 들어간 SQL 이 여기에 그대로 만들어집니다.
  3. 실행이 끝나면 위의 통계 열기 를 누릅니다.
